# 2026年9月 主一覧変換の実データ検証

2026-09-10に8地方厚生局・支局の公開ページから対象月のExcel/ZIPを取得し、保存原本を使って変換した。

| 項目 | 結果 |
|---|---:|
| 取得した主一覧Excel/ZIP | 30ファイル |
| 都道府県・種別coverage | 47県 × 医科・歯科・薬局 = 141組 |
| 医科 | 97,393件 |
| 歯科 | 64,960件 |
| 薬局 | 62,164件 |
| 合計 | 224,517件 |
| 同一10桁IDの内容競合 | 0 |
| 主一覧取得・解析エラー（修正後） | 0 |

原資料の指定レコード数であり、国内すべての物理施設数を示すものではない。近畿ZIP内の併設補助一覧12メンバーは主一覧から除外し、原本の中に保持した。各個別属性の意味や網羅性をすべて確認したという意味ではない。

初回の実行では近畿の補助一覧が通常一覧と異なるため不完全として停止した。主一覧との分離を修正し、ネットワーク再取得なしの再変換で全地域を確認した。東海北陸のWindows形式ZIPディレクトリと、Excelの使用範囲情報に依存しない読取も検証した。

聖路加国際病院（1310270751）とJR札幌病院（0110114386）の名称・郵便番号・電話を実資料の行と照合した。取得版・元URL・SHA-256は[構造化検証記録](validation-2026-09.json)に収録する。

生成bundle全224,517件を投入側のvalidatorに渡して受理されることを確認した。これはオフラインのデータ契約検証であり、Wikibaseへの実投入・実サーバーのProperty型照合ではない。

変更一覧についても別実行で8地域の候補取得経路を試した。PDF/XLSは保存まで、Excelはセル中間CSVへの抽出まで。候補の対象月には地域差があり、網羅性と意味解釈は未確定なので要確認とする。ここでのcomplete判定に変更イベントの完成を含めない。

ユニットテストは公開データを同梱せず合成Excelを生成して実行する。主な検証：対象月違い、副コード保持、複数行、A1 dimension、ZIPパス、同一ID競合、不完全時のbundle分離、資料差替えの非上書き保存、出典のみの変化の除外。
