# 医療機関コードの正本（2026-09-13承認）

ユーザーの明示判断により、旧Propertyの復元ではなく、Wikidata P13179（保険機関コード、external-id）に対応する新しい正本へ移行する。PPは誤字として廃止する。旧P2118/P1895本体の定義が未発見であることは履歴として残すが、新仕様の採用を止める条件ではなくなった。

## 識別子

canonical identifierは必ずASCII数字10文字の文字列。整数に変換せず先頭ゼロを保持する。

- 都道府県番号2桁（01〜47）＋点数表番号1桁（医科1、歯科3、薬局4）＋地域の医療機関コード7桁。
- 原資料が7桁なら、確認された都道府県・種別を付して10桁を生成する。7桁だけでは全国識別しない。
- 入力が10桁なら、そのまま保持して都道府県・種別との一致を検証する。
- 切り詰め、未知の県・種別の推定、欠落桁のゼロ埋めはしない。長さや文脈が矛盾する値はエラーとする。
- 名寄せ処理も10桁文字列を必須とする。コード一致だけでなく、名称・他属性の矛盾も確認してからQIDを付ける。
- 構成検証であり、チェックデジットや指定の有効性の検証を実装したものではない。

例：北海道の医科 0114386 → 0110114386、東京都の医科 0270751 → 1310270751。

WikidataのP13179という番号をローカル側に強制割当しない。既存bootstrapがローカルPropertyへWikidata PID（P13179）とWikidata entity URLを記録し、registry mappingを作成する。P1448、P281、P6375、P1329、P854も同じ方式を用いる。

## 移行と残作業

旧Property実体の削除はまだ行っていない。対象インスタンスの特定、利用statementと移行結果の確認が必要。新環境では旧Propertyを作成せず、新mappingのみ採用する。P1は医療番号ではないため一括削除の対象にしない。
